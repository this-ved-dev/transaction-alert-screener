# r04_dormant_reactivation

**Owner:** Vedanshu · **Ticket:** TRA-25 · **Process:** Account behaviour

Dormant reactivation: no customer-initiated activity for >=180 days, then >=$5,000 in or out within 7 days (or >=10x the prior 12-month average). The backtest demo rule (180 → 120 → 365 days).
